## Key Features

### HPC Education and Research

PARAM SHAVAK 2.0 provides a practical platform for students, researchers, educators, and scientific institutions to learn and develop HPC applications.

It enables users to gain practical experience in:

* Parallel computing
* HPC programming
* MPI programming
* Job scheduling
* Scientific computing
* Performance analysis
* HPC system administration

### Multidisciplinary Applications

The platform supports applications from multiple scientific and engineering domains, enabling users to perform computationally intensive workloads within a single HPC environment.

### Compact and Cost-Effective

PARAM SHAVAK 2.0 provides HPC capabilities in a compact system design, reducing the infrastructure requirements normally associated with large-scale supercomputing environments.

### Pre-Configured HPC Environment

The system is designed to provide an HPC-ready software environment containing essential development tools, compilers, libraries, workload management software, and scientific applications.

The software environment may include:

* Compilers
* MPI libraries
* Scientific libraries
* SLURM workload manager
* GPU computing software
* Scientific applications
* Development tools

### Energy Efficient

The compact design of PARAM SHAVAK 2.0 reduces the infrastructure requirements associated with conventional HPC environments.

### Indigenous Technology

PARAM SHAVAK 2.0 is developed by **C-DAC** as part of India's indigenous HPC technology ecosystem.

The platform is based on C-DAC's RUDRA server technology and is designed to support the evolution of indigenous computing technologies.

# Role of PS-BOSS Linux

PARAM SHAVAK 2.0 uses **PSBOSS (Param Shavak Bharat Operating System Solutions)**, an indigenous Linux OS on Rhel distribution developed by C-DAC, as part of its operating system environment.

BOSS provides the Linux foundation required for:

* System administration
* Application execution
* HPC workloads
* Software development
* User management
* Network configuration
* System monitoring

## HPC-Oriented Software Environment

The BOSS-based environment provides access to software required for HPC application development and execution.

Depending on the PARAM SHAVAK 2.0 configuration and software release, the environment may include:

* GCC
* Intel oneAPI
* MPI
* SLURM
* HPC libraries
* Scientific applications
* GPU computing libraries
* Linux development tools


## Ease of Use

BOSS provides users with a familiar Linux environment while integrating the tools required for HPC application development and execution.

This allows users to focus on scientific applications and computational workloads without requiring extensive system-level configuration.
